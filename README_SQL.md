# 🗄️ My SQL Learning Journey

Welcome to my comprehensive SQL reference guide! This collection represents my journey through mastering SQL fundamentals, from basic queries to advanced joins and subqueries. Whether you're starting fresh or need a quick refresher, this guide has got you covered!

## What's Inside? 📚

### Core SQL Operations
The building blocks of database querying:
- **Basic SELECT statements** - Your gateway to data retrieval
- **WHERE clauses** - Filtering data like a pro
- **Comparison operators** - BETWEEN, IN, NOT, and more
- **LIMIT and ORDER BY** - Controlling your results

### Aggregate Functions 📊
Making sense of your data:
- **COUNT()** - Counting rows that matter
- **SUM()** - Adding up numeric values
- **AVG()** - Finding the middle ground
- **MIN() & MAX()** - Discovering extremes
- **GROUP BY** - Organizing data into meaningful groups
- **HAVING** - Filtering groups with precision

### Data Manipulation 🔧
Keeping your data fresh:
- **UPDATE** - Modifying existing records
- **DELETE** - Removing unwanted data
- **ALTER** - Changing table structure
- **TRUNCATE** - Clearing table data
- **DROP** - Removing tables entirely

### Advanced Concepts 🚀
Taking your SQL skills to the next level:
- **Foreign Keys & Cascading** - Maintaining data integrity
- **JOINS** (INNER, LEFT, RIGHT, FULL) - Connecting related data
- **Subqueries** - Queries within queries for complex operations

## Key Concepts I've Mastered 🎯

### Query Execution Order
Understanding the SQL processing sequence:
```
SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
```

### Join Types at a Glance
- **INNER JOIN**: Only matching records from both tables
- **LEFT JOIN**: All records from left table + matches from right
- **RIGHT JOIN**: All records from right table + matches from left  
- **FULL JOIN**: All records from both tables

## Pro Tips 💪

- Always use WHERE clauses to avoid full table scans
- Remember the difference between WHERE (filters rows) and HAVING (filters groups)
- Use appropriate JOIN types based on your data requirements
- Practice with real datasets to solidify your understanding
